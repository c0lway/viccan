☁️ Sincronización entre dispositivos (GitHub Pages + Firebase)

Como GitHub Pages es un sitio estático, en Modo Local los datos se guardan únicamente en el navegador de cada dispositivo. Para que tus alumnos suban sus videos desde su casa y tú los revises desde tu computadora automáticamente, conecta una base de datos gratuita de Firebase Firestore pegando tu configuración en la constante FIREBASE_CONFIG dentro de index.html (o pruébalo primero aquí en este navegador).

Pasos rápidos para activar Firebase gratis:

  1. Crea un proyecto gratis en console.firebase.google.com.
  2. Activa Firestore Database (en modo prueba o con reglas para viccan_users y viccan_submissions).
  3. En Configuración del proyecto > Tus apps > Web, copia el objeto firebaseConfig.
  4. Pégalo en la línea const FIREBASE_CONFIG = { ... } de este archivo antes de subirlo a GitHub.
